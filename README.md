# abntstandard — registro de proposta histórica (2023)

> **Estado:** conceito/documentação histórica. A árvore consultada contém somente este README, **sem fontes de pacote LaTeX, testes ou subpacotes implementados**.

A ideia original era desenvolver uma implementação modular de normas ABNT para trabalhos acadêmicos em LaTeX. A referência à NBR 14724:2011 na descrição antiga identifica o contexto histórico, **não uma versão normativa atualmente validada**.

## Destino sugerido

Manter a proposta como registro da evolução intelectual do projeto, ou arquivar este repositório quando sua relação com protótipos posteriores estiver documentada. Não tratá-lo como distribuição instalável.
